```bash

python evals/run_precision.py sample --per-rule 20 --seed 1002 --out evals/labels/baseline
# label every entry: tp | fp | unsure, with a one-line note
python evals/run_precision.py report --labels evals/labels/baseline --out evals/precision-baseline.md
```
